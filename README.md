# 🚢 Titanic Classification

Predicting passenger survival on the Titanic using machine learning.

## Overview

Classic binary classification project based on the famous Titanic dataset. The goal is to predict whether a passenger survived based on features like age, sex, class, fare, etc.

## What's Inside

- `TITANIC_CLASSIFICATION.ipynb` — Complete analysis and modeling notebook
- `train.csv` — Training dataset

## Technologies

- Python
- Jupyter Notebook
- Pandas, NumPy
- Scikit-learn (or similar)

## How to Run

1. Clone the repository
2. Open the notebook in Jupyter / VS Code / Colab
3. Make sure `train.csv` is in the same directory
4. Run all cells

## Purpose

This project helped me practice the end-to-end ML pipeline:
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training & evaluation
- Handling missing values and categorical data
